下面这段代码，粘贴到 GitHub 网页创建 daily-briefing.yml 时用。

创建方法：
1. 浏览器打开这个 URL（把用户名和repo名换成你自己的）：
   https://github.com/你的用户名/你的repo名/new/main?filename=.github/workflows/daily-briefing.yml

2. 页面打开后，把下面从 "name: Daily Briefing" 到最后 "git push" 全部复制粘贴到网页的编辑框

3. 拉到底 → 点绿色 Commit changes... → 再点绿色 Commit changes

======= 从下面这行开始复制 =======

name: Daily Briefing

on:
  schedule:
    - cron: '0 0 * * *'
  workflow_dispatch:

permissions:
  contents: write

jobs:
  briefing:
    runs-on: ubuntu-latest
    steps:
      - name: 检出代码
        uses: actions/checkout@v4

      - name: 设置 Python 环境
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'
          cache: 'pip'

      - name: 安装依赖
        run: pip install -r requirements.txt

      - name: 运行每日晨报
        env:
          GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
          TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
        run: python main.py briefing

      - name: 提交生成的选题
        run: |
          git config user.name "MCP Radar Bot"
          git config user.email "bot@mc-prime.com"
          git add output/topics_*.json output/last_update_id.txt 2>/dev/null || true
          git diff --staged --quiet || git commit -m "Daily topics $(date -u +%Y-%m-%d)"
          git push
